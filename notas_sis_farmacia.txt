video 2: Instalacion de laravel 13 desde cero: Hola mundo, Autentiacion y conexion a base de datos, creamos el proyecto en laravel de esta forma -> ""composer create-project laravel/laravel sis_farmacia", despues de instalarse correctamente dicho proyecto
y probamos levantarlo, despues estando en la ruta del proyecto, lo podemos levantar con "code ." para que nos habra la raiz del proyecto con visual studio code, para la autenticacion de bootstrap, para ello ponemos el "laravel ui" -> "composer require laravel/ui"
y vemos que sea compatible, si es asi, ejecutamos el "php artisan ui bootstrap --auth", nos pregunta si queremos crear el controlador, le decimos que "yes", despues nos pide ejecutar "npm install", mientras se instale pasamos el archivo ".env" llamado mariaDB en la
base de datos llamado "sis_farmacia", en la base de datos le ponemos el lenguaje "utf8mb4_spanish_ci", ejecutamos "php artisan migrate" y debe ejecutarse las tablas y tambien el npm run dev
